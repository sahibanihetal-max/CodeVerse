
# CodeVerse — Learn. Build. Grow.

CodeVerse is a responsive programming learning platform designed to help learners explore programming concepts through explanations, code examples, practice questions, and progress tracking.

## Features

- Learning paths for Python, NumPy, Pandas, Matplotlib, HTML, CSS, Java, C/C++, DSA, AI/ML, SQL, Git/GitHub, and Generative AI
- Search and category filters
- Topic-wise explanations and code examples
- Expected output and common mistakes
- Interactive multiple-choice quizzes
- Browser-based learning progress tracking
- Responsive dark-themed dashboard

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Getting Started

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Explore the topics and attempt the quizzes.

For local development, you can also use the Live Server extension in Visual Studio Code.

## Project Structure

- `index.html` — Website structure
- `style.css` — Layout, theme, and responsive design
- `script.js` — Topic content, navigation, quizzes, and progress features

## Note

This is a frontend educational project. Code examples are learning material and are not executed inside the website. Learning progress is stored in the browser and may not sync across devices.
